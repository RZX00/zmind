# Canvas 清债报告目录

本目录存放 `canvas-enterprise-*` 计划产生的周报、基线报告与验收报告。

建议命名：

- `canvas-baseline-week1.md`
- `canvas-ops-diff-matrix.md`
- `canvas-contract-test-result-weekN.md`
- `canvas-migration-waveN-retro.md`

所有报告应至少包含：

1. 本期目标
2. 本期变更
3. 指标变化（before/after）
4. 风险与阻塞
5. 下期计划

## Trigger 相关报告

- `2026-03-01-trigger-full-parity-launch-plan.md`：Trigger 与旧仓最新实现完全对齐的上线实施总方案（含架构、迁移、测试、灰度、回滚）。
