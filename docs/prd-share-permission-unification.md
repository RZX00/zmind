# PRD - 分享与权限统一（Share & Access Unification）

## 1. 背景与问题（直指痛点）
- 分享入口分散且逻辑割裂：画布分享、对话分享、邀请协作各自成体系，用户无法形成稳定心智。
- 流程多一步且没价值：必须“生成链接”再“复制”，这是纯粹的操作噪音。
- 权限表达工程化：用户看到“public/private/thread”等术语，理解成本高。
- 登录/访问失败的反馈弱：被拒绝时缺少清晰解释与请求入口，导致流失。

## 2. 目标与非目标
**目标**
- 合并所有分享入口与权限模型，一次打开就能完成分享。
- 让用户只看到“谁能访问/能做什么”，不暴露底层实现。
- 在不牺牲安全性的前提下，极简默认、少选项。

**非目标**
- 不重构实时协作架构。
- 不重写后端数据模型（仅做必要的接口封装/映射）。
- 不引入复杂审批流程。

## 3. 目标用户与场景
- 画布所有者：需要快速分享给同事/客户。
- 协作者：需要快速进入且清楚自己权限。
- 外部访客：需要最少阻碍地查看内容或请求访问。
- 团队管理员：需要控制可公开/可匿名策略。

## 4. 设计原则
- **Result First**：打开即见链接，主动作仅“复制”。
- **One Click Policy**：能一键完成的，不允许两步。
- **No Jargon**：UI只说“访问”“编辑”“查看”。
- **Hide Complexity**：高级选项放进“设置”折叠。

## 5. 功能需求
### 5.1 统一分享面板
- 入口统一：画布顶栏、工作区卡片、上下文菜单、对话右上角共用同一面板。
- 打开面板即生成可用链接（若之前已生成则直接展示）。
- 主操作固定为“复制链接”，无“生成”按钮。

### 5.2 权限模型（对用户）
- 访问范围：`仅自己` / `有链接的人` / `公开`。
- 权限级别：`仅查看` / `可评论` / `可编辑`。
- 默认组合：`有链接的人 + 仅查看 + 需登录`。
- 高级设置（折叠）：匿名访问、过期时间、密码保护（可选）。

### 5.3 访问体验
- 打开链接：直接校验权限，符合则进入。
- 需登录：显示“登录继续”，登录后自动回跳。
- 无权限：显示“你没有权限”+“请求访问”按钮。
- 链接失效：显示“分享已关闭或过期”+“联系分享者”提示。

### 5.4 管理与撤销
- 一键关闭分享链接，UI上明确显示“已关闭”。
- 关闭后访问给出清晰说明页（不是空白或 404）。

### 5.5 数据与接口（高层）
- `GET /share-config` 获取当前分享配置（画布/对话统一）。
- `PUT /share-config` 更新权限与设置。
- `POST /share-token` 生成/刷新分享链接 token。
- 权限校验统一由后端判定，前端只展示结果状态。

## 6. 体验流程（低保真）
**Owner flow**
```
[Canvas 顶栏 Share]
        |
        v
[分享面板打开]
- 链接自动生成
- 访问范围/权限可见
- 主按钮：复制链接
        |
        v
[Copied + toast] -> 完成
```

**Invitee flow**
```
[打开分享链接]
   |
   +--> 权限 OK -> 进入画布
   |
   +--> 需登录 -> 登录 -> 回跳
   |
   +--> 无权限/过期 -> 说明页 + 请求访问
```

**权限变化**
```
[分享面板]
  |
  +-- 变更访问范围/权限
  |
  +-- 链接即时更新
  |
  +-- 复制/关闭
```

**面板线框图**
```
┌───────────────────────────────┐
│ 分享                           │
│ 链接: https://...     [复制]   │
│ 访问范围: 有链接的人   [v]     │
│ 权限: 仅查看           [v]     │
│ 设置 ▸（过期/密码/匿名）       │
│ 邀请邮箱（可选）              │
│ [关闭分享]                     │
└───────────────────────────────┘
```

## 7. 异常与降级
- 网络波动：保留已生成链接展示，提示“同步失败稍后再试”。
- 未加载配置：展示 skeleton，避免空白。
- 权限变更冲突：提示“已被管理员更新”并刷新状态。

## 8. 埋点与指标
- `share_panel_opened`
- `share_link_copied`
- `share_permission_changed`
- `share_link_opened`
- `share_access_denied`

**成功指标**
- 首次分享完成率提升
- 分享耗时下降（打开面板到复制）
- 访问拒绝后的二次转化提升

## 9. 开放问题
- 是否保留“可评论”权限档？
- 默认是否允许匿名只读？
- 是否需要链接过期的默认值？
- 管理员是否可强制禁用公开分享？
