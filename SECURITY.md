# Security Policy

## Supported Versions

The latest `main` branch is the only supported security target.

## Reporting a Vulnerability

Please do not open public GitHub issues for unpatched vulnerabilities.

Send a private report to: team@zmind.so
Subject: [SECURITY] <short summary>

Include:

1. Affected component and version/commit.
2. Reproduction steps or proof of concept.
3. Impact assessment.
4. Any suggested remediation.

## Response Targets

1. Initial acknowledgment: within 3 business days.
2. Triage decision: within 7 business days.
3. Fix timeline: based on severity and exploitability.

## Disclosure Process

1. We validate and triage the report.
2. We implement and test a fix.
3. We coordinate a disclosure window with reporter when possible.
4. We publish a security advisory.
